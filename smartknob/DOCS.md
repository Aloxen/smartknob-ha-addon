# SmartKnob Studio Home Assistant App (Add-on)

Visueller Menü- und Screen-Builder für den SmartKnob.

## Funktionen

- **Echte App in Home Assistant**: Erscheint dank Ingress direkt in deiner linken Seitenleiste.
- **Visueller Screen-Builder**:
  - Übersicht aller Menüs und Untermenüs.
  - Mit `+ Element hinzufügen` neue Lichter, Schalter, Info-Screens oder Untermenüs anlegen.
  - Sortieren und Verschieben mit Pfeiltasten.
- **Live Entity-Auswahl**:
  - Dropdown greift direkt auf deine echten Home Assistant Entitäten zu (`light.*`, `switch.*`, `sensor.*`).
- **Live 240x240 Display-Vorschau**:
  - Sieh sofort, wie das Menü oder der Screen auf dem runden Display des SmartKnob aussehen wird.
- **Echtzeit-Push**:
  - Klick auf *An Knob senden* überträgt die Konfiguration sofort per WebSocket an deinen SmartKnob.
